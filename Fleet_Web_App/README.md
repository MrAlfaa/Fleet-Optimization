# FleetOpt AI Web App

This folder contains the web application workspace.

- `frontend/`: runnable React + Vite + TypeScript + Tailwind dashboard
- `backend/`: placeholder for the future FastAPI backend

Run the frontend from PowerShell:

```powershell
cd "E:\PROJECTS\Out Source Project\AI Driven Fleet Optimization Project\Fleet_Web_App\frontend"
npm.cmd install
npm.cmd run dev
```

Build and test:

```powershell
npm.cmd run build
npm.cmd run test
```
